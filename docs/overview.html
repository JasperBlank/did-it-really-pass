Did it really pass?

A coding agent ends its turn with "done, the tests pass". did-it-really-pass has a second model read what the agent actually ran, and speaks up when the two don't match.

Built on 1,005 episodes of one person's Claude Code history

How it runs while you work

It installs as a Claude Code hook that fires each time the agent finishes a turn. A cheap model reads every turn. A stronger one is only called when the cheap one objects.

Your agent
Finishes a turn

Any Claude Code session. Turns with fewer than 3 tool calls are skipped.

Haiku 5.5
Reads the transcript

Every command, its output, the final message, and your last three requests. About 5 seconds and a tenth of a cent.

No objection: the turn ends. 85% of episodes
Opus 5.5
Checks the objection

Same transcript, stronger reader. About 15 seconds and 3 cents.

Rejected: the turn ends. 3 in 4 objections
Back to your agent
"Fix it, or correct what you said"

The agent gets the quoted line and the step, and has to answer before it can stop. You see the exchange.

Shares are from the history scan below. In live use so far it has checked 13 turns and objected to none.

Four models, four jobs

The tool is two models in a row. Checking whether the tool can be trusted took two more, and most of that checking ran as agents working in parallel.

Screens everything

Opus 5.5
Confirms a flag

Reviews with full context

Half the flags were wrong, so I went after the cause

Most wrong flags were the agent correcting a test it had written minutes earlier, or changing one because I had asked for new behaviour. Two changes, measured on the same 36 flags:

With both changes, 18 of 25 flags are right: 72%, up from 53%. One serious case is no longer flagged. These numbers are fitted to the same 36 flags they are measured on, so the live log has to confirm them.

What this does not show

  • One person's logs. Mostly game and research code. Your rate may be very different.
  • The planted failures are blatant. A model wrote them to order. Real ones are harder.
  • The reviewer is a model. Fable judged the 36 flags and the 40 unflagged episodes. I have read three of the serious cases myself.
  • Misses are loosely bounded. None in 40 still allows more misses than catches.
  • Nothing caught live yet. The hook has checked 13 turns and raised no flag.
  • Windows only so far. Not tried on macOS or Linux.
